# Awell · Parceiro autorizado Claro

**Site de vendas de planos de internet da Claro**, feito para a Awell, parceira autorizada. Cada plano leva o cliente direto para o WhatsApp do vendedor, com a mensagem pronta.

No ar em **[claropfpj.com.br](https://claropfpj.com.br)**

![Página inicial do site da Awell](docs/inicio.webp)

## O que ele faz

- **Início:** escolha da velocidade, separando empresa e casa.
- **Empresa (CNPJ)** e **Casa (CPF, São Paulo capital):** páginas de planos para cada tipo de cliente.
- **Monte seu combo:** o cliente empresa junta os serviços que quer.
- **Contato.**
- Todos os botões abrem o WhatsApp do vendedor com o plano escolhido já escrito na mensagem.

## Como foi feito

HTML, CSS e JavaScript puros, sem framework, banco ou servidor. Cada página funciona sozinha, com o estilo, o código e os logos dentro do próprio arquivo. O número do WhatsApp e o e-mail ficam num bloco `CONFIG` em cada página, então o cliente troca o contato sem mexer no resto.

Hospedado no GitHub Pages, com domínio próprio.
